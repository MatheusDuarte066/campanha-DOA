# Campanha D.O.A.

Site da campanha de RPG: guia de criação de Tributos e Dívidas, ficha de herdeiro e painel do mestre.

- `index.html`: guia e ficha para os jogadores.
- `mestre.html`: painel do mestre, protegido por senha conferida pela planilha.
- `assets/ficha.js`: configuração (link do Apps Script e WhatsApp do mestre) e lógica compartilhada.
- `assets/estilo.css`: visual do site.
- `apps-script/Code.gs`: código para colar no Apps Script da planilha do Google.

A senha do painel fica só no Apps Script, nunca neste repositório.
